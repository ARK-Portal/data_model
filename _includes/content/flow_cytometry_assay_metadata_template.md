# Flow Cytometry Assay Metadata Template
A template outlining assay-related metadata for a flow cytometry dataset. Each row corresponds to a vial of cells that were profiled in the experiment to generate the raw data.
### Instructions
The template collects assay-level metadata for your flow cytometry data. Each row is expected to correspond to a single vial of cells that were sampled. If your vials contained a pool of multiple samples please reach out the ARK Portal team for further instructions.
