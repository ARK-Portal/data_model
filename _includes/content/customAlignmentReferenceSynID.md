# customAlignmentReferenceSynID
If a custom alignment reference was used for aligning your reads, then the reference files should be grouped as a zip or tar archive and uploaded to Synapse as metadata. This attribute links the experimental data back to the custom reference files via a Synapse ID. This includes genomomic, transcriptomic, and proteomic reference sequence information as well as 10x Genomics Flex probe sets.


{: .note }
There are no defined valid values for this model attribute.
