# Feature Barcode Sequencing Assay Metadata Template
A template outlining metadata to be collected for each library that sequences feature barcodes, typically in a multi-modal sequencing experiment like CITE-seq.
### Instructions
This template collects assay-level metadata for the feature barcode, aka ADT, libraries. Each row is expected to correspond to a single library that was generated and sequenced. libraryID is expected to be unique within this template and should correspond to the librayIDs specified for concomitantly generated libraries, e.g., scRNA-seq libraries in a CITE-seq experiment.
