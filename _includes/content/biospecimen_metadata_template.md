# Biospecimen Metadata Template
A general template outlining metadata to be collected for biospecimen profiled in a dataset.
### Instructions
This template collects information about the biospecimen, aka samples, used to generate data. One row represent a distinct biospecimen. Each biospecimenID is expected to be unique within this template and more broadly across a given program. The same biospecimenID are expected to be used in corresponding Assay and File Annotation templates.
